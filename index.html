أنا مطورة ويب مستقلة (Freelancer)، متخصصة في بناء وتصميم المواقع الإلكترونية بالكامل من الصفر. أعمل بشكل حر ومستقل تماماً لتقديم حلول برمجية ذكية وسريعة تناسب احتياجات عملائي وأصحاب المشاريع، مع الحفاظ على هوية بصرية فريدة لكل مشروع.

🛠️ التقنيات واللغات (Tech Stack)

HTML5 CSS3 JavaScript (ES6+) Bootstrap / Tailwind Node.js Express.js MongoDB / SQL Git & GitHub

💼 الخدمات التي يمكنني تقديمها لك:

  • تصميم واجهات المستخدم (Frontend): بناء صفحات ويب متناسقة، جذابة، وتعمل بكفاءة عالية على الموبايل والتابلت والكمبيوتر.
  • برمجة الأنظمة الخلفية (Backend): إدارة البيانات وحفظها وتأمينها خلف الكواليس لضمان عمل موقعكِ بسلاسة.
  • تطوير واجهات كاملة (Full-Stack): تسليم مشروعك جاهزاً ومكتملاً من الصفر دون الحاجة للاستعانة بأدوات جاهزة مقيدة.
